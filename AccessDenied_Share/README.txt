This zip contains the playable p5.js version of the project.

How to run it:

1. Unzip the folder.
2. Open a terminal inside the WarGamesMain folder.
3. Run:

   python3 -m http.server 8000

4. Open a browser and go to:

   http://localhost:8000

5. The game will start from index.html.

Notes:

- Do not move index.html away from the other files.
- WarGamesMain.js, VT323-Regular.ttf, and libraries/p5.min.js need to stay together.
- If python3 is unavailable, opening the folder with VS Code Live Server is another easy option.
